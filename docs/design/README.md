# Linee guida di design (fonte: Figma Resource Library)

Mappa: leggi il file che serve, non tutti.

- `tipografia.md` — scelta font, abbinamenti, Poppins e alternative
- `principi-grafici.md` — 13 principi (allineamento, contrasto, gerarchia, spazio bianco, ritmo…)
- `principi-ui.md` — 7 principi UI + consigli (gerarchia, divulgazione progressiva, coerenza, accessibilità…)
- `ux-design.md` — processo UX, principi, best practice
- `product-design.md` — principi, processo, sfide del product design

Checklist rapida per ogni schermata:
1. Un solo punto focale (enfasi) e gerarchia chiara.
2. Elementi correlati vicini, non correlati separati (prossimità + spazio bianco).
3. Un bordo/griglia di allineamento coerente.
4. Contrasto sufficiente (WCAG), aree di tocco adeguate.
5. Stessi componenti/colori/font ovunque (coerenza/ripetizione).
6. Mostra solo ciò che serve ora (divulgazione progressiva).
7. Azione annullabile, feedback visivo chiaro.
