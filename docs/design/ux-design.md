# UX design

UX = problem-solving + design visivo per prodotti intuitivi, basato su comportamenti e obiettivi degli utenti. UX = esperienza complessiva (ricerca, test, bisogni); UI = aspetto (pulsanti, colori, layout).

## Responsabilità
User research, wireframe/prototipi, information architecture, user testing, design iterativo.

## Processo in 5 fasi
1. **Definire il problema** — cosa serve, cosa si vuole, cosa è difficile; problem statement, flow chart.
2. **Ricerca** — interviste, sondaggi, test, analisi prodotti esistenti; user persona; AI per analizzare feedback.
3. **Prototipi** — interattivi, schermate collegate, flussi simulati, prima dello sviluppo.
4. **Test e feedback** — usability test, A/B test, contextual inquiry (utenti nel loro ambiente).
5. **Iterazione** — analytics post-lancio (engagement, conversioni, soddisfazione), sondaggi, social.

## 7 principi
1. Centrato sull'utente (bisogni/comportamenti reali)
2. Coerenza (prevedibile tra schermate e dispositivi)
3. Gerarchia (segnali visivi per l'importante)
4. Usabilità (facile da imparare e usare)
5. Controllo utente (annullare, gestire l'esperienza — es. annulla invio)
6. Accessibilità (tutte le abilità, sottotitoli, alt text)
7. Contesto (come/quando/dove: pulsanti più grandi nelle app mobile bancarie)

## Best practice
- Utente al centro in ogni fase; allinea il team prima della ricerca.
- Testa presto con prototipi; design = processo iterativo.
- Accessibilità fin dall'inizio, non alla fine.
- Monitora metriche dopo il lancio; cura l'handoff (specifiche chiare).
- Competenze: teamwork, empatia, creatività, problem-solving, ricerca, prototipazione, metriche di business.
